AcadEase 

AcadEase is a Java-based Student Academic Record Management System developed using Object-Oriented Programming (OOP) concepts and MySQL.
It is a console-based application that helps manage student details, subject information, marks, and academic performance records.

Technologies Used

Programming Language: Java

Database: MySQL

Database Connectivity: JDBC

IDE: Eclipse

Concepts: Object-Oriented Programming (OOP), DBMS

Features
Student Management – Add, view, search, update, and delete student details.
Subject Management – Manage subject information.
Marks Management – Add, view, search, update, and delete student marks.
Calculate Student Results.
View Student Academic Reports.
Search and Filter Records.
Class Performance Statistics.
Find Subject Topper.
Semester-wise Progress Tracker.
Low-Marks Alert.

Database Structure
The project uses a MySQL database named AcadEaseDB with three main tables:
Students – Stores student details.
Subjects – Stores subject information.
Marks – Stores students' marks and semester details.
The SQL database export is provided in AcadEaseDB.sql.

How to Run the Project
Prerequisites
Java Development Kit (JDK)
Eclipse IDE
MySQL Server
MySQL Workbench

Setup Instructions
Download or clone this repository.
Create the MySQL database by importing AcadEaseDB.sql through MySQL Workbench.
Open the Java project in Eclipse.
Add the MySQL Connector/J JAR from the lib folder to the project's Build Path.
Open DatabaseConnection.java.
Update the database username and password with your own MySQL credentials.
Run MainMenu.java to start the application.

Project Purpose
This project demonstrates the practical application of Java OOP concepts and MySQL database management through a simple academic record management system.
